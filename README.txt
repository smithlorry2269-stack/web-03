Crumb — Artisan Bakery & Patisserie Website Template

Crumb is a warm, hand-made website template for bakeries, patisseries and cake
shops. It includes a rich one-page home and a dedicated menu-and-order page, with
a tabbed priced menu, an add-to-bag cart, a pickup/custom-cake order form, a photo
gallery with lightbox, locations with live opening hours, testimonials and a
newsletter sign-up. It is built on Bootstrap 5 (self-hosted) with vanilla
JavaScript and no jQuery, is fully responsive and progressively enhanced so all
content stays visible with JavaScript disabled. Crumb is free for both personal
and commercial use. Crafted by uiCookies (https://uicookies.com/).
